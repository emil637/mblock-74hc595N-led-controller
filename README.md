# mblock-74hc595N-led-controller

(i used an arduino uno, but you can use another arduino if you want)

an programm on mblock that can control 2 leds on the 74hc595N with the following key:

1 (for the first led to turn on)

2 (for the second led to turn on)

q (for the first to turn off)

w (for the second to turn off)

pin occupancy:

1 (Qb) : first led

2 (Qc) : second led

8 (GND) : GND 

10 (SRCLR) : 5V

11 (SRCLK) : digital pin 3

12 (RCLK) : digital pin 4

13 (OE) : GND

14 (SER) : digital pin 2

16 (VCC) : 5V
